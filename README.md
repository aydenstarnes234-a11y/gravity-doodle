# Gravity Doodle

A tiny browser toy: draw shapes on the canvas, let go, and watch them fall and collide under real physics.

## How it works

- Draw a stroke with your mouse or finger — a quick tap becomes a circle, a longer stroke becomes a solid shape.
- Shapes fall under gravity ([Matter.js](https://brm.io/matter-js/)) and bounce off the walls and each other.
- Drag any shape around at any time.
- Pick a color from the swatches and adjust brush size with the slider.
- **flip gravity** reverses which way things fall.
- **clear** removes everything from the canvas.

## Running it

No build step — just open `index.html` in a browser.

```bash
open index.html
```
